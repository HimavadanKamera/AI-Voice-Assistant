# 🤖 AI Voice Assistant (Jarvis)

An intelligent Python-based voice assistant that can understand voice commands and perform tasks like automation, answering questions, and storing memory.

## 🚀 Features

* Voice recognition
* AI-based responses
* YouTube & Google automation
* Memory system
* Text-to-speech output

## ⚙️ Installation

git clone https://github.com/HimavadanKamera/AI-Voice-Assistant.git
cd AI-Voice-Assistant
pip install -r requirements.txt

## ▶️ Run

python main.py

## 🧪 Example Commands

* Play songs on YouTube
* Search Google for AI news
* Remember this note
* Open Notepad
